# Modern Portfolio Website

A modern, responsive portfolio website template that you can easily customize and host on GitHub Pages.

## Features

- Modern and clean design
- Fully responsive layout
- Smooth scrolling navigation
- Animated sections
- Contact form
- Skills showcase
- Project showcase
- Social media links

## How to Use

1. Clone this repository to your local machine
2. Customize the content in `index.html`:
   - Replace "Your Name" with your actual name
   - Update the about section with your information
   - Add your skills
   - Add your projects
   - Update social media links
3. Add your profile photo:
   - Save your photo as `profile.jpg` in the root directory
   - Make sure the photo is square and high quality
4. Add project images:
   - Save your project screenshots as `project1.jpg`, `project2.jpg`, etc.
   - Place them in the root directory

## Customization

### Colors
You can change the color scheme by modifying the CSS variables in `style.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --text-color: #1f2937;
    --light-bg: #f3f4f6;
    --white: #ffffff;
}
```

### Fonts
The website uses the system font stack, but you can change it by modifying the `font-family` property in the `*` selector in `style.css`.

## Hosting on GitHub Pages

1. Create a new repository on GitHub
2. Push your code to the repository
3. Go to Settings > Pages
4. Select the main branch as the source
5. Your portfolio will be live at `https://yourusername.github.io/repositoryname`
